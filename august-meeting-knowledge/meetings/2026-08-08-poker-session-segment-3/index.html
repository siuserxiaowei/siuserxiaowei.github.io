03

可迁移知识

知 01

先做三态来源分离，再做语义总结

为什么重要
现场麦克风会同时收进参会者、手机视频、影视对白和环境声音；自动转写把它们统一编号后，流畅文本很容易制造错误归因。
怎么使用
按连续时间窗将内容标为“确认现场、疑似背景媒体、来源不明”，记录判断依据；只有确认现场且上下文连续的片段才能进入会议结论。
适用边界
文本中的话题突变和叙事口吻只能提示来源异常，不能替代音轨核听、设备声道或参会者确认。
知 02

标题只用于检索，不用于证明内容

为什么重要
标题可能来自人工命名、前一分段或整场活动，而当前分段可能没有相应正文；依据标题补写会让知识库失去可追溯性。
怎么使用
为目标主题预先定义最低证据清单，并逐项寻找真实时码；关键项全部缺失时输出 insufficient，同时转入资料恢复。
适用边界
这项判断只说明当前分段不能支持扑克复盘，不否认未转写音频或其他分段中可能发生过牌局。
知 03

覆盖度异常是内容生成的停止信号

为什么重要
长录音只有零散文字和大段空档时，缺失可能来自静音、识别失败、导出截断或产物错配；任何一种都会让总结产生系统性偏差。
怎么使用
统计首末时码、发言块、最大空档和连续区间，核对录音、逐字稿及前后分段；未解释的关键缺口保留为限制，不用常识填充。
适用边界
时间空档本身不能证明发生了什么，也不能区分无人说话与转写故障。
知 04

扑克过程复盘需要事件台账而非印象叙述

为什么重要
没有局次、席位、筹码和行动顺序，就无法判断当时面对的信息、选择和结果，更无法让缺席者复算或与 Agent 讨论。
怎么使用
补证后为每手牌记录匿名参与者、位置、起始筹码、强制下注、每轮公开信息与行动、底池变化、结果、当事人理由及复盘疑问；未知项明确留空。
适用边界
这是从当前资料缺口反推的通用记录模板，不代表本段实际采用了这些规则，也不构成赌博或财务建议。
知 05

给 Agent 的知识应同时携带证据等级

为什么重要
Agent 会倾向把连贯叙事继续补全；若没有来源标签和停止条件，背景节目也可能被吸收到组织知识中。
怎么使用
每条输入附上时码、来源类别、置信度、可支持的结论和禁止推断项；要求 Agent 先做证据矩阵，再输出不足、假设或建议。
适用边界
Agent 的分类仍需人工抽查，涉及身份、安全、金钱或声誉的内容不能仅凭自动判断发布。
04

道 · 法 · 术 · 器 · 势

  1. 道01

    知识库的首要责任是忠于来源；无法确认谁在说、是否在开会和是否发生过牌局时，承认不足比制造完整故事更有价值。

  2. 法02

    采用覆盖度审计、三态来源分离、扑克领域证据门槛、资料补取和独立复核五步流程，未过门槛就不生成牌局结论。

  3. 术03

    统计首末时码与空档，观察话题连续性和叙事口吻，逐窗标记来源；补证后再用匿名手牌事件台账重建行动链。

  4. 器04

    原始音轨、完整逐字稿、前后分段、来源时间线、手牌记录表、证据矩阵、隐私清单与双人复核记录共同构成工具链。

  5. 势05

    手机短视频和环境媒体进入长时录音已是常见污染源；越依赖自动转写批量建库，越需要把来源分离和停止条件设计成默认门禁。

你是会议来源审计与扑克过程复盘 Agent。先按时间窗输出证据表，字段包括时码、内容概述、来源类别（确认现场 / 疑似背景媒体 / 来源不明）、分类依据、置信度和允许支持的结论。禁止根据标题、自动关键词、说话人编号或扑克常识补写牌局。随后检查最低领域证据：活动规则、匿名席位、起始筹码、强制下注、手牌或局次编号、每轮公开信息与行动、底池变化、结果和复盘理由。若这些证据不能组成至少一个连续过程，明确输出 insufficient，只列资料缺口、补取顺序和停止条件。若补证后过门槛，再生成匿名事件台账，并把每条结论标为原始证据、参与者观点、分析推断或通用建议。背景媒体不得作为会议观点；涉及个人身份、安全、金钱、连接配置或私人业务的信息必须删除或泛化。
复制包同时携带公开来源状态、知识卡、待核验主张、局限与证据锚点。

三态来源卡

每个时间窗只标为确认现场、疑似背景媒体或来源不明；来源不明不参与会议结论，直到音轨或知情者完成复核。

扑克证据门槛卡

至少需要一个连续局次的匿名席位、起始状态、逐轮行动与结果，才能开始过程复盘；只有标题或牌局氛围不算证据。

手牌事件台账卡

按局次记录位置、筹码、强制下注、公开信息、行动、底池、结果、当时理由和复盘问题；未知项留空，不让 Agent 猜。

Agent 停止条件卡

标题与正文不匹配、关键来源无法确认、长空档未解释或领域证据不成链时，输出 insufficient 并转入补证。

知识边界卡

原始证据、参与者观点、分析推断和通用方法分别存放；背景节目、孤立数字和自动关键词不得升级为组织知识。
