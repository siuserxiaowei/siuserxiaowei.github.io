IMAGE ATLAS / GUIDE

关于图鉴

一个开放共建的图像作品与提示词图鉴：发现创作者、学习画面方法，记录自己的尝试。

本站如何运行

本站部署在 GitHub Pages，由静态 HTML、CSS、JavaScript 和媒体文件组成。本站没有注册、登录或自己的后端接口，也不在站内接收提交；想贡献内容，请转到项目 GitHub 的公开 Issue。

页面中的案例来自公开来源或项目记录。作者、提示词作者、图片作者、上游收录者和本项目编辑可能是不同角色；页面按已有记录分别展示。

浏览和搜索

搜索、分类和模型筛选在你的浏览器中完成。本站当前没有接入独立的访问分析或广告展示脚本。

标题和分类是编辑整理字段，用于检索与浏览，不改变原始作品、作者或许可。
