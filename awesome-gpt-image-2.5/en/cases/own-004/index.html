What this example teaches

List recognition features once, then specify which features should be visible from each view. Separate visual presentation from engineering accuracy.

Observed limitations

The existing review found three full-body views and the requested eyes, antenna, chest button and battery cover. The side view faces left and shows one eye near the screen edge. Engineering orthographic accuracy and consistency across separate generations were not tested.

Complete submitted prompt

The prompt is kept in its original language to preserve exact wording and Chinese typography. The English text above is an editorial guide.

请直接生成一张横向角色设计图，比例 3:2，纯白背景。

设计一个原创的小型玩具机器人，并在同一张图上展示三个等高、全身完整的视图：左侧正面，中间右侧面，右侧背面。三个视图必须是同一个机器人。

机器人特征固定：圆角方形的奶油白色头部，头顶正中一根短天线，天线末端为橙色小球；头部正面有一块深蓝色圆角屏幕，屏幕内只有两只青色圆形眼睛，没有嘴；橙色圆角箱体作为躯干，胸前正中一个深蓝色圆形按钮；两条短奶油白色手臂和两条短奶油白色腿，深蓝色圆形手套和深蓝色平底鞋。背面躯干有一块深蓝色矩形电池盖。

采用细腻的哑光塑料玩具质感，柔和的摄影棚光，每个视图脚下有淡淡的接触阴影。保持头身比例、颜色、天线、四肢和鞋子在三个视图中一致。侧面按真实遮挡显示，背面不能出现脸部屏幕或胸前按钮。

三个视图之间留出充足间距。不要文字、标签、其他机器人、道具、边框或水印。
