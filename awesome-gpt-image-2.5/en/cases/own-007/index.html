What this example teaches

Use a fixed character description and one persistent prop to connect the panels. Enumerate the action in reading order.

Complete submitted prompt

The prompt is kept in its original language to preserve exact wording and Chinese typography. The English text above is an editorial guide.

请直接生成一张儿童绘本六格故事板，横向 3:2，采用三列两行布局。六格大小相同，白色间隔一致，按从左到右、从上到下的顺序讲述完整故事。

主角始终是同一只橙色小狐狸：白色口鼻、黑色耳尖、穿蓝色短外套、斜挎黄色邮差包。它要把一封绿色信封送给住在树洞里的小刺猬。整张图不要任何文字或数字。

第一格：清晨，狐狸在自己的木屋门口拿起绿色信封。
第二格：狐狸把信封放进黄色邮差包，沿森林小路出发。
第三格：狐狸小心走过溪流上的木桥。
第四格：狐狸来到小刺猬的树洞门前，抬起一只前爪敲门。
第五格：小刺猬打开门，狐狸从包里取出同一封绿色信封递给它。
第六格：狐狸和小刺猬坐在树洞门口一起喝茶，绿色信封放在两者之间的矮桌上。

采用温暖的彩铅与不透明水彩插画，柔和的上午自然光。狐狸的颜色、服装、包和体型在六格中保持一致，绿色信封的颜色保持一致。每格只呈现该格要求的动作，不要重复角色、额外格子、水印或文字。
