What this example teaches

Separate approximate style matching from countable requirements. Count every visible paper layer and check whether foreground elements hide the subject.

Observed limitations

The existing review found convincing paper texture and shadows, but extra detail layers prevented confirmation of exactly five paper layers. Grass hid the deer’s feet; the sun was not an exact semicircle. The output was 1672 by 941 pixels, close to 16:9.

The existing review was an AI-assisted visual inspection of the saved image, not an independent regeneration. PNG metadata reports generator gpt-image, version 2.0; its signature and mapping to the ChatGPT product version have not been verified. This does not establish either API variant.

Complete submitted prompt

The prompt is kept in its original language to preserve exact wording and Chinese typography. The English text above is an editorial guide.

请直接生成一张横向 16:9 的多层纸雕艺术作品正面图，不要文字。

画面是晨光中的山谷，必须清楚呈现五层有厚度的切割纸张：最前层是深墨绿色的草叶；第二层是一只站在左下方的赭红色小鹿；第三层是由左向右蜿蜒的浅蓝色河流和两岸森林；第四层是有三个山峰的灰蓝色群山；最远层是淡杏色天空和一轮从群山后露出上半部的圆形太阳。

每一层纸都有细微纤维、干净的切割边缘和真实厚度，层与层之间有清晰但柔和的投影。暖光从左上方照入，所有阴影方向一致。正面观看，山谷中央保留通透空间，构图平衡，小鹿完整可见。

作品应呈现真实手工纸雕的材质，不要变成油画、塑料模型或照片风景。不要相框、玻璃反光、文字、标志、水印或额外动物。
