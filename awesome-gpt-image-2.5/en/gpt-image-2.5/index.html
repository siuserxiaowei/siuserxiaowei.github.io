What is verified here?

The project contains actual images and visual reviews: earlier contributors reported GPT Image 2.5, while 30 examples were generated directly with built-in image_gen in Codex. The tool did not return an exact model ID. Each case retains its own evidence; none is independently verified as 2.5.

The earlier nine records include saved PNG metadata reporting generator gpt-image, version 2.0. Its signature and mapping to the ChatGPT product version have not been verified. Neither the repository name nor a visual impression identifies Flare or Sunburst.

How to make your next result useful

  • Keep the exact prompt, reference inputs and original output.
  • Record the actual model identifier or product-version evidence, quality, size and timing method. Leave unrecorded values unknown.
  • Keep output pixel dimensions separate from the request size.
  • Review exact text, object counts, product identity and unwanted changes.
  • Preserve failed attempts and record each revision instead of keeping only the best image.

Imported learning references

The larger collection includes upstream GPT Image 2 and other reported-model examples. Their original labels and creator links remain intact. Reusing a prompt on a new model is an experiment, not proof of compatibility.
