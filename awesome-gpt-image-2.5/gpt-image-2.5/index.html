ChatGPT 与 API 型号如何区分

OpenAI 于 2026 年 9 月 8 日介绍 ChatGPT Images 2.5，并公布 GPT-Image-2.5 Flare 和 GPT-Image-2.5 Sunburst。ChatGPT 产品名称与 API 型号要分别记录；不要用仓库名或图片风格判断底层型号。

Flare vs Sunburst：官方定位与对照方法

把一次生成变成能核对的案例

  • 保存完整原始提示词、参考图要求与实际结果。
  • 记录实际入口、模型 ID 或产品版本依据、请求 quality 和 size；没记录的字段写“未记录”。
  • 将输出像素尺寸与请求 size 分开，不要用下载文件尺寸反推 API 参数。
  • 保留耗时测量方式、失败输出与每轮修改，不只展示最好的一张。
  • 逐条检查中文、对象数量、品牌外形、遮挡与编辑后主体变化。
