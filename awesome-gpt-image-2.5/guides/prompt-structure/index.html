提示词结构：把画面拆成六个可测试变量

用主体、环境、色材形、光线、镜头、排版六个要素写出可读的产品海报提示词，并用单变量方法逐项比较。

先建立六要素骨架

写提示词时，可以把画面想成一张拍摄单。主体回答‘画什么’，环境回答‘放在哪里’，色材形回答‘表面和轮廓是什么感觉’，光线回答‘从哪里照、阴影多硬’，镜头回答‘从多远、以什么角度看’，排版回答‘文字和留白如何落位’。六项都写到，模型更容易把要求当成同一幅画，而不是互不相干的形容词。

  • 主体：数量、尺寸、姿态、关键结构和不可出现的标识。
  • 环境：地面或台面、背景层次、空间关系和必要的道具。
  • 色材形：主色与辅助色、表面触感、边缘形状和反光程度。
  • 光线：主光方向、软硬、色温、轮廓光和阴影落点。
  • 镜头：视角、景别、焦段感、画幅比例、主体位置和留白。
  • 排版：标题内容、字数、对齐方式、层级、区域和安全留白。

一个无品牌产品海报范例

下面是一条原创的结构示范，产品是无品牌的日常物件。它没有指定模型，也没有声称已经运行过；示例的作用是展示如何把六项要求放进同一条提示词。先读完整版本，再按下一节拆开测试。

制作一张竖版、写实的无品牌产品海报，画面主体是一只 450 ml 的哑光陶瓷保温杯，圆柱杯身，细窄直筒杯口，浅灰木纹杯盖，杯盖边缘有一圈细小的暖橙色硅胶环；杯身正面保持纯净，不出现品牌、标志、人物、手、条码或水印。

环境：杯子立在浅米色石材台面上，背景是同色系的整洁墙面，台面与墙面在后方形成柔和的水平交界，旁边只放一片干燥的橙色叶片，空间安静、留白充足。
色材形：陶瓷表面细腻、微微吸光，杯身边缘圆润，木纹杯盖有真实细纹，暖橙色只作为小面积环带和叶片色点；避免塑料质感、过度镜面反射和夸张变形。
光线：左上方的大面积柔光，右侧保留很淡的轮廓光，杯子向右后方投下边缘清楚但不生硬的短阴影，整体为自然的中性暖色。
镜头：相机与杯身中段接近水平，略高于台面，三分之二正面视角，接近 50mm 的自然透视，中近景，杯子位于画面中央偏右，顶部和左右保留呼吸空间，4:5 竖幅。
排版：左上角放两行黑色无衬线文字‘日常饮水’和‘450 ML’，字号有明显层级，文字不遮挡杯子；其余区域不放文字，边缘保持干净。

先换什么，如何逐项测试

第一版先只求主体清楚：保留杯子的结构、视角和 4:5 画幅，背景写得简单，先检查杯口、杯盖和杯身是否稳定。主体一旦不稳定，后面比较材质或光线就没有意义。主体稳定后，依次测试镜头、环境、色材形、光线，最后才测试排版；每一轮只换一处，其他句子原样保留。

  • 测镜头：只在‘水平三分之二视角’与‘正面略俯视’之间切换，比较轮廓和留白是否更合适。
  • 测环境：只替换台面和背景，例如‘浅米色石材’换成‘暖灰亚麻布’，观察材质对主体识别的影响。
  • 测色材形：只改杯身颜色或表面光泽，保留光线不变，检查颜色是否吞掉边缘。
  • 测光线：只改主光方向或软硬，比较阴影是否帮助读出圆柱体，而不是增加杂乱反光。
  • 测排版：最后加入标题和数值文字，短文案逐步增加；若文字挤压主体，先恢复留白再改字号或位置。

输入图、来源与模型边界

有些案例的效果依赖输入图、参考图或原始照片。若这张图没有随案例提供，不能只凭文字复刻人物、物体细节、构图或材质，也不能把相似主题的新作写成原结果。你可以明确标注‘缺少输入图，以下为独立尝试’，并把能确认的部分和无法核对的部分分开说明。

模型名称、版本、入口、日期和复现状态属于来源记录。引用案例时，应以案例详情页和其上游记录为准；本指南的原创范例没有模型归属，也不把某一版本的表现当成保证。

  • 先核对原作者、原帖或上游仓库，再决定是否引用提示词。
  • 保留输入要求；缺图时停止‘复刻’表述，改为记录独立测试。
  • 把自己的结果和上游结果分开描述，避免用一张新图替代来源证据。
