参考图使用：先分清保留项，再做可追踪改图

把参考图拆成构图、配色、材质、光线和排版，先判断哪些条件齐全，再开始自己的改图测试。文中的指令是原创模板，没有声称已经运行或验证。

先判断参考图值得保留什么

参考图不等于整张图一键照搬。先找决定画面身份的关系：主体数量与相对位置、视线方向、地平线和留白属于构图；主色、明度和冷暖对比属于配色；表面粗糙度、透明度、纹理尺度和边缘形状属于材质；主光方向、阴影软硬和反光位置属于光线；镜头距离、视角、画幅和文字落位则决定观看方式。

值得保留的是能被准确描述、能在下一版核对的条件。装饰性的花纹或氛围词可以后置；如果某个细节无法从图中确认，就写成待确认项，不要用想象补齐。

  • 先锁定主体、构图和画幅，再比较配色、材质与光线。
  • 把‘感觉高级’改写成可观察的色值关系、表面触感、阴影边缘或留白比例。
  • 每轮保留上一版和原参考图，便于判断变化来自哪一句。

缺少输入素材时，先判断能否复刻

先核对案例有没有提供原始照片、参考图、人物设定或其他输入。如果只有成品截图和一段文字，无法据此确认原始构图、人物身份、物体细节或材质来源；用相似素材做出的新图应记录为独立尝试。缺图时可以复用已知的色彩、镜头和布局要求，但不能把猜测写成原始条件。

只有当输入素材可取得、来源清楚、主体数量和关键关系可核对时，才适合使用‘复刻测试’这个说法。输入是私有的、链接失效的、来源不明的，或关键人物与品牌细节没有记录，就应停止复刻表述，改为‘参考方向测试’。

  • 可复刻测试：参考图和必要输入齐全，且能说明来自哪里。
  • 独立尝试：缺少一张或多张输入图，只保留能从公开页面确认的结构。
  • 暂停测试：来源、授权状态或关键素材无法核对，先补记录再继续。

三轮改图指令：保持项 → 修改项 → 目标 → 限制

下面三轮文字可直接复制到已有参考图的编辑对话中，每轮从上一轮结果继续。它们是改图指令模板，不是 API 调用，也不代表本项目已经运行、复现或验证了结果。若没有参考图，请先补齐输入，并把任务名称改为独立尝试。

【第一轮｜先锁定构图】
请基于当前参考图执行一次图像编辑。
保持项：主体数量、主体相对位置、画幅比例、地平线高度、主要视线方向和整体留白；保持原参考图的主色冷暖关系。
修改项：把背景中的次要道具减少到一个，并让主体边缘更清楚。
目标：得到一张构图关系稳定、主体一眼可辨的版本，方便下一轮比较材质。
限制：不要新增主体、不要改变主体姿态或裁切比例，不添加文字、标志、水印和额外装饰。

【第二轮｜校准配色与材质】
请基于上一轮结果执行一次图像编辑。
保持项：主体数量、位置、镜头角度、画幅、背景层次和阴影落点。
修改项：将主色调整为参考图的低饱和暖灰与暗橙关系；主体表面改为细腻的哑光材质，只保留轻微边缘反光。
目标：让颜色层级清楚，材质触感可辨，同时不吞掉主体轮廓。
限制：不改变构图，不把哑光表面变成镜面，不增加纹理、图案、品牌标志或新的光源。

【第三轮｜只修光线与排版】
请基于上一轮结果执行一次图像编辑。
保持项：主体形状、配色、材质、相机视角、画幅和背景道具。
修改项：把主光固定为左上方柔光，减弱右侧杂乱反光；在左上留白处加入两行短标题，使用无衬线字，第一行较大、第二行较小。
目标：让阴影帮助读出体积，文字与主体有清晰层级并保持呼吸感。
限制：不得遮挡主体，不改动标题字面，不生成不可读的伪文字，不加入边框、徽标或水印；若留白不足，宁可缩小文字也不要移动主体。

读结果时，把失败拆成可修的变量

第一轮若主体位置或画幅已经漂移，先回退并修构图，不要急着讨论材质。第二轮若颜色相近但表面仍像塑料，单独改材质词和反光限制；若阴影方向错了，回到光线条件。第三轮的文字错误、遮挡和伪标志要单独记录，不能用‘整体相似’掩盖。每轮只改一个层次，失败才有可解释的原因。

  • 构图失败：主体数量、位置、比例或留白不对。
  • 外观失败：配色、材质、边缘或反光不对。
  • 信息失败：文字、标志、人物身份或输入关系无法确认。

记录日期、模型和每次失败

每次测试都保存原参考图、输入素材清单、完整指令、输出文件和失败说明，并在文件名或日志中写下日期与时区、产品入口、报告的模型名称或版本。若模型信息只能从界面推断，就标为‘界面显示’，不要补写未确认的版本。记录‘哪一轮失败、看到什么、下一轮改了什么’，比只留下最好看的一张图更有复盘价值。

本页示例没有对应的运行记录，因此不能作为模型效果、复刻成功率或结果已验证的证据。

  • 日期：YYYY-MM-DD、时区和轮次。
  • 模型：产品入口、界面显示名称、能否确认的版本。
  • 输入：参考图、原图、遮罩或缺失项。
  • 结果：保留项是否稳定、失败点、下一步修改和是否停止。

人物、品牌与来源

涉及真实人物、品牌标识或可识别作品时，尽量使用你有权使用且能说明来源的素材，并把原作者、改编者和自己的测试记录分开。这里是创作流程提示，不是法律意见；具体使用范围请自行核对适用规则或咨询专业人士。
