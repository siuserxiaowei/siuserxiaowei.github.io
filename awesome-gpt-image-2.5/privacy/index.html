隐私说明

本站当前是无注册、无站内提交后端的静态 GitHub Pages 网站；本页记录当前页面代码与外部服务状态。

本站当前处理

本站不提供账户系统、站内表单或后端提交接口。搜索、筛选和复制提示词等交互在浏览器完成；页面当前没有加载访问分析或广告展示脚本。

浏览器仍会向 GitHub Pages 请求页面、媒体和静态数据；你打开作者、GitHub 或其他外部链接后，相关网站会按各自政策处理请求。

Google 服务当前状态

本站已登记 AdSense 申请站点，但当前仍待审核，尚未获批，也未展示广告。未来若启用广告，本站会先更新本页，说明所加载的广告服务和相关数据处理，再加载相应脚本。

Search Console 验证文件已准备在站点根目录；如启用 Search Console，搜索表现统计将由 Google 处理，当前页面代码未自行发送搜索统计。
