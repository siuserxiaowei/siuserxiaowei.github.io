  • 协同范式演变：企业协同从会话式到清单式，再到系统式。会话式如一对一安排工作，对应 AI 工具是打开会话框输入 prompt 输出内容；清单式借助 agent 完成复杂任务，但存在割裂和需完整上下文输入的问题；系统式如 SAP、金蝶等企业系统，天然承载任务上下文。

  • Cody 与 agentos：Cody 是 agent 的办公室，可管理 agent 编排，共享企业知识上下文、数据和系统内容；agentos 是具身硬件。
