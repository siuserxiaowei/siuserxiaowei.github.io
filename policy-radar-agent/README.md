# 智策雷达

智策雷达是面向制造业与中小企业的 AI 政策搜索与申报助手。它会定时回到政府公开来源核验政策目录，生成可追溯快照；企业画像和排序仍在浏览器本地完成。

## 解决的问题

政策发布渠道分散、更新频繁、字段格式不统一。企业通常需要人工查找、阅读和判断适用性，容易错过窗口期，也难以解释“为什么这条政策与我有关”。

智策雷达把这一过程压缩为一个可追溯闭环：

1. 汇集政府官方网站与政府公报中的政策信息。
2. 统一地区、行业、企业规模、时限和支持方向等字段。
3. 根据查询意图与企业画像计算可解释匹配度。
4. 输出排序后的政策机会、命中依据和原文证据。
5. 一键生成可继续加工的 Markdown 政策研判简报。

## 核心能力

- 中文语义扩展：把“AI、人工智能、大模型、智能体”等表达映射到同一检索空间。
- 企业画像匹配：综合地区、行业、规模、发展诉求和政策状态评分。
- 可解释排序：每条结果给出地区、行业、企业规模、主题和有效性依据。
- 生命周期管理：区分有效、已截止和长期政策，支持窗口期跟踪。
- 权威证据链：数据样本全部附政府官方网站或政府公报链接。
- 本地隐私：企业画像默认只在浏览器内计算，不上传、不保存。
- 零运行依赖：核心演示只使用浏览器原生能力与 Node.js 标准库。
- 定时自动核验：GitHub Actions 每日 4 次读取已配置的政府公开来源。
- 失败安全：只有全部来源抓取并通过校验才替换快照；任一来源失败就保留上一版。
- 来源透明：页面区分“自动核验”与“人工核验基线”，显示最近成功时间和来源健康。

## 本地运行

需要 Node.js 20 或更高版本：

```bash
npm start
```

打开 `http://127.0.0.1:4173`。

手动执行一次官方来源刷新：

```bash
npm run refresh
```

## 验证

```bash
npm test
npm run check
```

测试覆盖查询扩展、画像匹配、状态筛选、评分边界、来源证据和作者信息。

## 数据说明

当前自动覆盖范围是脚本中明确配置的东莞市工业和信息化局政府信息公开目录，不代表全网政策库。静态 GitHub Pages 读取的是定时生成的 JSON 快照，不会在每次访问时实时爬取。自动抽取只发布通过 HTTPS、日期和必要字段校验的记录；无法从正文确认的申报截止时间保持为空并提示回看原文。

`src/data.js` 中的跨地区样本属于人工核验基线，用于自动来源不可用时维持演示和搜索能力。页面不会把人工样本显示成自动抓取结果。

产品不替代主管部门的正式政策解释。涉及申报资格、资金支持和截止日期时，应以官方最新通知为准。
