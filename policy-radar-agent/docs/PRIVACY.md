# 隐私与数据边界

作者：siuser小伟

## 当前版本

- 企业画像只在当前浏览器内存中计算。
- 页面不使用 Cookie、分析脚本、广告脚本或第三方字体。
- 页面不会上传企业名称、联系人、联系方式、文件或搜索历史。
- 源码不包含真实 API 密钥、账号密码或个人联系方式。
- 公开身份仅保留作品作者“siuser小伟”。

## 政策来源

政策样本只保留政策名称、政府机构、日期、主题字段、简短摘要和官方链接。页面不收录政策正文中的个人联系方式或个人姓名。

## 使用边界

智策雷达用于信息筛选与辅助研判，不替代主管部门的正式解释。提交申请前必须回到官方原文确认资格、材料、时限和执行口径。
