# 知乎 AI Works 项目页文案

## 项目名称

智策雷达｜有证据的 AI 政策研判助手

## 一句话介绍

输入政策问题和企业画像，智策雷达会基于可追溯的政府公开来源，给出可解释排序、官方链接和可下载的行动简报。

## 项目简介

政策搜索真正困难的部分，往往不是找到文件，而是回答三个问题：这条政策和我的企业有没有关系？申报窗口是否还有效？判断依据在哪里？

智策雷达把这个过程做成一个浏览器内的政策研判工作台。用户可以输入自然语言问题，再设置地区、行业、企业规模和发展诉求。系统通过中文查询规范化、同义概念扩展和确定性加权规则，对政策记录进行初筛和排序，并把“标题命中、地区覆盖、行业匹配、当前有效”等理由直接展示出来。

每条结果保留发布机构、政策状态、申报截止时间、来源标识和政府原文链接。用户还可以把优先政策与建议动作导出为 Markdown 简报，继续交给同事核对或补充材料。

这不是一个替人下结论的“申报神器”。它更像一层可检查的研判界面：先缩小阅读范围，再把关键判断带回官方原文。

## 当前数据范围

- 自动数据范围仅限项目中明确配置的东莞市工业和信息化局公开栏目，不代表全网或全国全部政策。
- 页面读取最近一次成功生成的静态 JSON 快照，不会在每次访问时实时抓取政府网站。
- 跨地区政策使用 9 条人工复核基线；自动快照不可用时，页面会明确降级到这组基线，不把两种来源混为一谈。
- 当前记录数、最近核验时间和来源健康，以页面顶部显示的快照元数据为准。
- 无法从官方正文严格确认的截止时间保持为空，并提示用户回到原文核对。

## 核心功能

1. **政策问题检索**：对输入做规范化、分词片段和 7 组同义概念扩展，例如把“AI、人工智能、大模型、智能体”等纳入同一组规则。
2. **企业画像匹配**：综合地区、行业、企业规模、发展诉求、政策状态和发布时间进行加权排序。
3. **可解释结果**：每条结果最多展示 4 个匹配理由；页面中的分数只用于排序，不代表资格、补贴金额或获批概率。
4. **来源与状态追溯**：区分自动核验快照与人工核验基线，展示机构、截止时间、证据要点和官方链接。
5. **行动简报导出**：导出 Top 3 政策、企业画像、匹配依据、官方来源、快照信息和下一步建议。
6. **失败安全降级**：只有来源全部成功且记录通过校验，刷新流程才发布新快照；失败时保留上一版可信数据。浏览器无法读取自动快照时，会显示降级状态并使用人工基线。

## 技术架构

```text
政府公开目录与详情页
        ↓
来源白名单、HTTPS、日期与必要字段校验
        ↓
正文截止时间提取、规范化与去重
        ↓
全部来源成功后原子写入 JSON 快照
        ↓
静态页面加载自动快照；异常时降级到人工基线
        ↓
浏览器本地完成查询扩展、画像匹配和可解释排序
        ↓
政策清单、官方证据与 Markdown 行动简报
```

实现使用原生 HTML、CSS、JavaScript 和 Node.js 标准库。当前排序不是大模型、向量检索或 RAG，而是公开可检查的确定性规则；这样做牺牲了一部分语言泛化能力，但结果更容易复现和解释。

## 使用方法

1. 输入一个具体问题，例如“东莞制造企业近期可申报的人工智能与数字化政策”。
2. 选择地区、行业、企业规模和发展诉求。
3. 查看排序结果及匹配理由；留意“自动核验”或“人工核验基线”标签。
4. 打开“查看官方证据”，核对发布机构、截止时间和政府原文。
5. 导出 Markdown 简报，作为进一步核验和准备材料的起点。

## 真实性与使用边界

- 智策雷达不是实时、全网政策库，也不承诺覆盖全部政策。
- 当前版本没有使用大模型语义检索、向量数据库或自主申报 Agent。
- 页面显示的匹配分是启发式排序分，不是官方评分或申报成功率。
- 自动提取与人工整理的证据要点都必须回到政府原文复核，尤其是资格、资金、材料和时限。
- 应用代码在浏览器内存中处理企业画像，不主动上传企业名称、联系人、文件或搜索历史；这不等于对 GitHub Pages 等托管平台的基础访问日志作出承诺。
- 系统只辅助信息筛选，不替代主管部门解释，也不会自动提交申报材料。
